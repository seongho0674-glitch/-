# 🪙 서초롱 민주시민 경제교육

> **초등학교 6학년을 위한 게이미피케이션 학급경제 & 3D 세계 지도 탐험 웹 애플리케이션**  
> 선생님 과제와 1인 1역으로 코인을 벌고, 세금을 납부하며, 나만의 캐릭터와 영토를 키워요.

## 이번 학급 설정

- 제공된 번호 순서의 학생 21명과 10개 부서의 장관·차관 등 21개 직책을 기본 배정합니다. 요일을 나눠 맡는 환경부 장관, 입법부 국회의장·부반장 등의 담당도 표시합니다. (학생 이름은 `class-roster.json`에만 둡니다)
- 학급 상점: **학용품 200코인**, **간식 뽑기 50코인**, **알림장 면제 100코인**.
- **교사 관리자**에서 과제 내용을 쓰거나 **PDF(파일당 3MB까지)**를 첨부하고 전체 또는 선택한 학생에게 게시합니다. 학생은 **미션 → 선생님 과제 → 풀고 인증하기**에서 PDF를 읽고 답안을 작성한 뒤 완료를 인증합니다. 교사는 **미션 → 답안 보기**에서 승인하거나 반려합니다. 승인된 과제는 중복 보상을 받을 수 없습니다.
- 학생 메인 **오늘의 세금**에서 소득세 10코인을 매일 납부합니다. 현재 잔액이 100코인을 넘으면 재산세 10코인도 납부합니다. 두 세금은 각각 하루 한 번 납부하며 거래 내역에 남습니다.
- **내 캐릭터 키우기**에서 레벨업마다 10·20·30…1,000코인을 사용합니다. 캐릭터는 1레벨에서 시작하여 최고 101레벨까지 자라며, 활동 경험치 레벨과 별도로 표시됩니다.
- 영토 확장과 새 도시 개척은 공통으로 **200·400·600…코인**을 사용하고 매번 정확히 **1칸**씩 늘어납니다.
- 기존 학생 ID, 잔액, 경험치와 거래 기록을 보존하면서 명부와 새 상품을 처음 한 번 적용합니다. 이후 선생님이 편집한 이름·역할·가격은 새로고침해도 유지합니다. 명단의 원본은 `class-roster.json`, 체험 모드 설정은 `js/class-roster.js`입니다.

교실의 서로 다른 기기에서 기록을 함께 쓰는 방법은 두 가지입니다. ① **웹 주소(Vercel + Neon 데이터베이스)**: 인터넷만 되면 어디서나 같은 기록을 씁니다. ② **교실 PC 서버(실행하기.bat)**: 같은 와이파이에서 접속하고 기록은 교실 PC의 `data/db.json`에 저장합니다. 두 버전은 규칙과 백업 파일 형식이 같습니다.

## 🌐 바로 접속하기 (Vercel + Neon)

- **배포 주소**: [https://classclass-gamma.vercel.app/](https://classclass-gamma.vercel.app/)
- 기록은 **Neon(Postgres) 데이터베이스**에 저장되어 학생 태블릿·크롬북과 교사 PC가 같은 기록을 봅니다.
- **선생님 첫 로그인**: 처음 PIN으로 들어가면 설정 화면이 열립니다. 새 PIN을 저장해야 다른 메뉴가 열립니다. (웹 주소는 누구나 열 수 있어서 처음 PIN은 쓸 수 없습니다)
- **학생 로그인**: 처음 한 번 **학급 코드**를 입력하면 이름 목록이 보입니다. 이름을 고르고 **개인 PIN 4자리**를 입력합니다. 학급 코드와 학생 PIN은 처음 실행할 때 무작위로 정해지며, 선생님 **설정**에서 확인하고 바꿀 수 있습니다.
- 데이터베이스가 연결되지 않은 상태로 열리면 시작 화면에 **체험 모드**가 표시됩니다. (그 브라우저에만 저장)

## 🚀 수정한 앱 배포하기

1. `푸시하기.bat`를 더블 클릭합니다. 수정한 앱 파일을 새 버전으로 저장하고 GitHub의 `main` 브랜치로 전송합니다.
2. 전송이 완료되면 Vercel의 자동 배포가 시작됩니다. Vercel 배포가 완료된 뒤 위 배포 주소에서 새로고침하세요. GitHub 전송 완료와 Vercel 배포 완료는 별도 단계입니다.
   - 배포 주소 뒤에 `/api/health`를 붙여 열면 연결 상태를 확인할 수 있습니다. `"db": "ok"`면 정상, `"missing"`이면 Vercel 프로젝트의 **Storage** 메뉴에서 Neon 데이터베이스를 연결한 뒤 다시 배포합니다.
3. `data/`에 있는 실제 학급 기록과 `backup_`으로 시작하는 백업 폴더는 전송하지 않고 PC에 그대로 보관합니다. 기본 명부와 1인 1역 설정은 앱 소스에 포함됩니다.

오류가 표시되면 전송 성공으로 처리하지 않습니다. 오류 내용을 확인한 뒤 다시 실행하세요.

## ✨ 핵심 기능

### 1. 🪙 학급 화폐 & 은행 시스템
- **원클릭 화폐 지급/차감**: 칭찬, 발표, 1인 1역 보상, 숙제 완료 등 교사가 한 번의 클릭으로 코인 지급.
- **성장형 경험치(EXP) & 레벨 시스템**: 코인을 획득하면 경험치가 쌓여 레벨이 오르고 멋진 레벨업 연출을 제공합니다.
- **거래 내역 투명 공개**: 언제 얼마를 벌고 썼는지 학생 본인의 거래 내역을 실시간으로 확인.

### 2. 🌍 Classimal World 3D 지구본 탐험
- **진짜 세계지도**: Natural Earth 1:110m 지리 데이터로 177개 나라의 국경·해안선·큰 호수를 그립니다. 나라는 교실 지도처럼 이웃끼리 다른 색으로 칠하고, 대륙·바다 이름을 한국어로 보여 줍니다.
- **지구본 ↔ 평면 세계지도**: 3D 지구본과 우리 교과서처럼 태평양을 가운데 둔 평면 세계지도를 버튼 하나로 바꿉니다. (교사 화면은 전자칠판용으로 평면 지도부터 보여 줌)
- **나라 이름 알아보기**: 나라 위에 마우스를 올리거나 손가락으로 누르면 한국어 나라 이름이 나옵니다. 도시 상세창에는 위도·경도도 표시됩니다.
- **부드러운 조작**: 드래그·관성 회전, 휠·두 손가락 확대, 방향키·`+`/`-` 키, 도시로 날아가는 애니메이션. 외부 라이브러리 없이 순수 HTML5 Canvas로 그립니다.
- **21개 글로벌 도시 & 랜드마크**:
  - 서울(경복궁), 밴쿠버(캐나다 플레이스), 뉴욕(자유의 여신상), 파리, 런던, 카이로, 시드니 등 21개 도시 탐험.
  - 도시별 역사·문화 정보 및 위키백과 연동.
- **수호동물 & 영토 점령 (게이미피케이션)**:
  - 25종의 고유 수호동물(여우 모리, 토끼 토리, 아기곰 밤이 등)과 칭호.
  - 탐험 에너지를 소모하여 도시 타일을 점령하고 학급 친구들과 함께 세계 지도를 채워나가는 협동형 게임.

### 3. 🛍️ 학급 상점 & 쿠폰
- **학급 특권과 물건**: 자리 바꾸기 교환권(150), 일일 선생님(120), 숙제 하루 면제(100), 급식 먼저 먹기(60), 음악 들으며 공부(40), 알림장 면제(100), 학용품(200), 간식 뽑기(50).
- **즉시 구매 및 소지품함**: 학생이 구매하면 보유 쿠폰함에 보관되며, 사용 시 교실에서 선생님 확인 후 사용 처리.

### 4. 🎯 미션 (화폐를 버는 방법)
| 미션 | 보상 (화폐·경험치) | 신청할 때 적는 것 |
|---|---|---|
| 📝 선생님 과제 | 과제마다 교사 설정 | PDF/과제를 풀고 답안·완료 인증 제출 |
| 🧩 1인 1역 (매일) | 10 | — (맡은 역할이 있어야 함) |
| 🗂️ PYPX 아카이빙 | **30** | 무엇을 기록·정리했는지 |
| 💡 PYPX 탐구 해결 | **40** | 해결한 탐구 질문 |
| 📖 독서노트 | 10 | 읽은 책 제목 |
| 📒 알림장 (매일) | 5 | — |
| 🎒 준비물 챙겨오기 (매일) | 5 | — |
| 🔎 PYP 관련 독서 인증 | 15 | 책 제목과 관련된 탐구 주제 |

- 학생이 "했어요!"를 누르면 선생님 화면의 **🎯 미션**에 확인 대기로 쌓이고, 선생님이 승인하면 화폐와 경험치가 같이 들어옵니다. 일반 미션은 하루 한 번, 선생님 과제는 각 과제마다 한 번 보상을 받아요.
- 선생님은 학생 여러 명을 골라 지급할 때 **미션 버튼**을 눌러 한 번에 줄 수도 있어요 (그날 이미 받은 학생은 자동으로 건너뜀).
- 미션 이름·보상·설명은 선생님이 고치거나 새로 만들 수 있어요.

### 5. 🏃 자율 체육 저금통 & 학급 회의
- 반 전체 학생의 화폐를 더해 **10일치**(학생 수 × 매일 미션 보상 합계 × 10일, 21명이면 4,200)가 모이면 선생님이 **학급 회의**를 열 수 있어요.
- 학생들은 자기 기기에서 찬성·반대를 누르고(비밀 투표), **전체 학생의 70% 이상**이 찬성하면 자율 체육을 해요.
- 통과하면 목표 금액만큼 모두의 잔액에서 **같은 비율**로 화폐를 함께 써요. 목표 일수는 설정에서 바꿀 수 있어요.

### 6. 🍀 행운의 게임 (홀짝)
- 손 안의 구슬이 홀수일지 짝수일지 맞히는 게임: 맞히면 건 화폐의 **2배**, 틀리면 **0배**.
- 한 번에 **10**(기본 미션 1개만큼)만 걸 수 있고, **하루 5번**까지, 할 때마다 **수수료 10%(1)**가 사라져요.
- 맞힐 확률은 반반이라 평균을 내면 한 번에 −1씩 줄어들어, 오래 할수록 결국 잃게 된다는 것을 화면의 기록과 설명으로 배워요. 사라진 수수료는 학급 화폐 총량을 줄여 물가 오름(인플레이션)도 막아요. 선생님이 설정에서 끌 수 있어요.

### 7. 🧑‍🤝‍🧑 1인 1역할 관리
- **학급 자치 활동**: 칠판 지킴이, 전등 관리자, 분리수거 대장 등 역할별 임무를 확인하고, 할 일을 다 체크하면 1인 1역 미션을 신청해요.

## 💻 교실 PC 오프라인 로컬 서버 실행 방법

학교 교실의 제한된 네트워크 환경에서도 교실 PC 한 대만 있으면 학생들(태블릿/크롬북)과 같은 와이파이에서 완벽하게 사용할 수 있습니다.

### 실행 방법
1. 이 저장소를 다운로드하거나 클론합니다.
2. `실행하기.bat` 파일을 더블 클릭합니다.
   - 또는 터미널에서 `python server.py` 실행 (파이썬 3 기본 내장 모듈만 사용, 추가 패키지 설치 불필요).
3. 교실 PC 화면에 브라우저가 자동으로 열립니다 (`http://localhost:8000`).
4. 안내되는 IP 주소(예: `http://192.168.0.x:8000`)를 칠판에 적어두면 학생들이 접속할 수 있습니다.
5. 모든 데이터는 `data/db.json` 파일에 안전하게 저장됩니다.

## 🛠️ 기술 스택

- **프론트엔드**: Vanilla HTML5, CSS3 (Modern Glassmorphism & Micro-animations), Vanilla JavaScript (ES Modules).
- **그래픽스**: Pure Canvas 2D 기반 지도 엔진 (`js/world3d.js`) — 지구본(정사 도법, 지평선에서 나라를 정확히 잘라 그림)과 평면 지도(Natural Earth 도법).
- **지도 데이터**: `assets/world-110m.json` — [Natural Earth](https://www.naturalearthdata.com/) 1:110m (퍼블릭 도메인)을 앱용으로 압축한 파일.
- **웹 백엔드**: Vercel Python 함수(`api/index.py`)가 `server.py`의 규칙을 그대로 쓰고, 데이터는 **Neon Postgres**에 저장합니다. 필요한 패키지는 `requirements.txt`(psycopg)입니다.
- **교실 백엔드 (로컬)**: Python 3 `http.server`, `ThreadingHTTPServer` (표준 라이브러리 100%, 추가 설치 없음).
- **체험 모드**: 서버나 데이터베이스가 없을 때 브라우저 LocalStorage에 저장합니다.

### 웹 버전 데이터(Neon) 메모

- 표 4개를 처음 실행할 때 자동으로 만듭니다: `app_state`(학급 기록 전체), `app_sessions`(로그인, 토큰의 해시만 저장), `app_login_failures`(PIN 연속 오류 잠금), `app_pdfs`(과제 PDF).
- Vercel 함수는 한 번에 4.5MB까지만 주고받을 수 있어서 **PDF는 3MB까지** 올릴 수 있습니다.
- 날짜와 '오늘'은 항상 **한국 시간** 기준입니다. (Vercel 서버는 UTC)
- 웹 버전의 백업 파일에는 PDF 본문이 들어가지 않습니다. PDF는 Neon의 `app_pdfs` 표에 남아 있습니다.
- 교실 PC 백업 파일을 웹 버전에 불러오면 기록이 옮겨지고, 선생님 PIN과 학급 코드는 웹 버전 값이 유지됩니다.

## 🗂️ 파일을 고칠 때 주의할 점

- 교실 서버(`server.py`)와 **Vercel은 `public/` 폴더**를 화면으로 보여 줍니다. (Vercel은 `api/` 폴더의 서버 기능도 함께 배포) `index.html`, `css/`, `js/`, `assets/`를 고치면 `public/` 안의 같은 파일도 똑같이 맞춰 주세요.
- 서버 규칙은 `server.py` 한 곳에만 있습니다. 교실 PC와 웹 버전이 같은 규칙을 씁니다.
- 서버 없이 열면(GitHub Pages 등) **체험 모드**로 작동하며, 기록은 그 브라우저에만 저장됩니다. 시작 화면에 체험 모드 안내가 표시됩니다.
